# Archived engineering notes

`correctness.md` and `completed.md` are retained checklists/logs from earlier
implementation sessions. Their dates, open items, and status claims are not the
current agenda. Start with the repository [README](../README.md) and
[current status](../docs/STATUS.md); use these files only for historical detail.

Runtime data may also land here (game logs, crash reports, driver DLLs); such
machine-specific data is git-ignored.
